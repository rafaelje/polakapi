# Security Policy

## Supported Versions

Security fixes are provided for the latest published release and the current `main` branch.
Older releases may not receive security updates.

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting page:

https://github.com/rafaelje/polakapi/security/advisories/new

If private vulnerability reporting is unavailable, contact one of the maintainers through a private contact method listed on their GitHub profile:

- [@rafaelje](https://github.com/rafaelje)
- [@miguelfiguera](https://github.com/miguelfiguera)

Include the following information when possible:

- A description of the vulnerability and its impact.
- The affected version, operating system, and installation method.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation or remediation.
- Whether the vulnerability is already public or under active exploitation.

The maintainers will acknowledge the report as soon as practical, investigate it, and coordinate disclosure after a fix or mitigation is available. Please avoid public disclosure until that process is complete.

## Scope

Reports may cover the polakapi source repository, GitHub Actions workflows, official release artifacts, Tauri permissions, local command execution, data storage, or integrations with supported AI CLIs.

Reports about vulnerabilities in third-party services or CLIs should also be sent to the relevant upstream project.
